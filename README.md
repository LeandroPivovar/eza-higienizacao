# Limpeza & Higienização (Rogério Varela) - site institucional

Site one-page de **Limpeza & Higienização**, com Rogério Varela: limpeza de caixa d'água, limpeza de calhas e higienização completa. Atendimento 24 horas.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato, FAQ)
styles.css   # estilos (azul-marinho, azul e branco da arte, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # marca em SVG, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Nome:** o perfil do WhatsApp está em nome de Rogério Varela e não há marca. A arte diz "LIMPEZA / HIGIENIZAÇÃO" (o "EZA" visível no topo é o fim de "LIMPEZA"). O site usa **Limpeza & Higienização** com Rogério Varela como responsável. Se houver um nome de empresa, troque no `<title>`, no cabeçalho, no rodapé e nos dados estruturados. O repositório se chama `eza-higienizacao`, mas o nome não aparece no site.
- **Logo:** não há logo. O site usa uma marca simples em SVG (`assets/marca.svg`, gota com check).
- **Telefone:** o perfil mostra `+55 61 9944-3445` e a arte `61 99944-3445`. O site exibe o número da arte; o link do WhatsApp usa `wa.me/556199443445` (o número do perfil).
- **Cidade:** o DDD 61 é do Distrito Federal, mas o site não cita região. Confirme onde atende.
- **"Higienização completa":** a arte não detalha o que entra. A foto e o texto falam em lavagem; confirme com o cliente.
- **Fotos:** de banco de imagens. Fotos reais de caixas d'água e calhas limpas (antes e depois) deixam o site mais forte.
- **Depoimentos:** não há seção de depoimentos para não publicar avaliações inventadas.
